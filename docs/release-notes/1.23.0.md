# TCG Binder 1.23.0

The mobile interface, rebuilt — nothing is lost on a phone anymore.

## Changed

- **Collection on narrow screens**: the 11-column table becomes stacked two-line rows — thumbnail, name and quantity stepper on top; set, variant, condition, playset, price and paid below. Variant and condition are chips that open a native menu (a bottom sheet on mobile), replacing the in-table dropdowns that could hide the view when focused.
- **Filters on narrow screens** collapse behind a "Filters" disclosure with a badge for how many are active, and active filters show as removable chips.
- **Deck toolbar on narrow screens**: format, status, "Add cards" and "Build" stay; everything else moves behind one ⋯ menu. Stat tiles become a 2×2 grid.
- **Dashboard covers on narrow screens** shrink to a square thumbnail so the collection/deck name keeps the row; names wrap to their own line instead of ellipsizing.
- **Tooltips that carried meaning are now visible on touch**: the deck's missing-cards dot becomes a "{n} missing" chip.
- All dropdown-like controls use the platform's native menu on touch — no more focused inputs inside the view (the known mobile hazard).

## Added

- **Swipe** left/right on the card detail flips between cards (arrow keys still work on desktop).
- The portfolio chart responds to touch (tap/drag reads values).
- Touch targets of at least 44px on every button, stepper and row action when a coarse pointer is detected.

## Fixed

- Missing-list rows wrap on narrow screens instead of cramming six elements into one unreadable line.
- Set progress rows give the bar its own full-width line on phones.
